# 📘 Web Học Từ Vựng Tiếng Nhật N4 — Minna no Nihongo

Ứng dụng web học và ôn tập 482 từ vựng tiếng Nhật cấp độ N4 theo giáo trình Minna no Nihongo (Bài 26–50), phân loại theo 12 nhóm từ vựng và hỗ trợ chế độ quiz tương tác báo đúng/sai trực quan.

![Giao diện](assets/bg.png)

## ✨ Tính Năng Nổi Bật

- **4 Cột Dữ Liệu**:
  - 🇯🇵 **Tiếng Nhật** (Kèm nút loa 🔊 phát âm bản xứ ja-JP)
  - 🇻🇳 **Tiếng Việt** (Nghĩa tiếng Việt chuẩn theo Minna no Nihongo)
  - 漢字 **Kanji** (Chữ Hán chuẩn N4)
  - 📜 **Hán Việt** (Âm Hán Việt)
- **Chế Độ Học Tương Tác**:
  - Tùy chọn ẩn bất kỳ cột nào trong 4 cột để tự điền kiểm tra.
  - Phản hồi trực quan: ✅ **Đúng báo màu xanh lá**, ❌ **Sai báo màu đỏ** kèm gợi ý đáp án đúng.
  - Tính năng **Ôn Lại Câu Sai** để luyện tập lại những từ chưa thuộc.
- **Tự Động Xáo Trộn (Auto Shuffle)**:
  - Tự động trộn ngẫu nhiên thứ tự từ vựng mỗi lượt học.
- **Tùy Biến Số Lượng Câu**:
  - Cho phép nhập trực tiếp số lượng từ muốn học (hoặc chọn nhanh 10, 20, 30, 50, Tất cả).
- **Bộ Gõ Romaji Thông Minh**:
  - Tự động chuyển đổi từ Romaji sang Hiragana theo thời gian thực (ví dụ gõ `tabemasu` -> `たべます`), không cần cài bộ gõ tiếng Nhật.
- **12 Bộ Từ Phân Loại Chuẩn (482 từ)**:
  - Danh từ, Động từ Nhóm 1, Động từ Nhóm 2, Động từ Nhóm 3, Tính từ -い, Tính từ -な, Phó từ, Trợ từ, Liên từ, Trợ số từ (đếm từ), Thán từ, Đại từ.

## 🚀 Cách Cài Đặt & Sử Dụng

1. Clone repository về máy:
   ```bash
   git clone https://github.com/DucHuy-cmd/WebTiengNhat.git
   ```
2. Mở file `index.html` trực tiếp trên bất kỳ trình duyệt nào (Chrome, Edge, Firefox, Safari...).
